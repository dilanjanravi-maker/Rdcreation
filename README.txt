RD CREATIONS — PHOTO CROPPER (OFFLINE ANDROID PROJECT)
=====================================================

WHAT IS INCLUDED
- Android Studio source project
- Offline photo cropper interface (HTML/CSS/JavaScript)
- Android WebView wrapper with photo picker and Downloads saving
- No INTERNET permission is requested; the editor works offline

QUICK USE ON ANDROID (NO APK BUILD REQUIRED)
1. Copy RD-Creations-Photo-Cropper.html to your Android phone.
2. Open the file with Chrome (or another modern browser).
3. Tap Select Photo and choose an image.
4. Drag the crop frame / handles to select the area.
5. Use the Crop, Rotate, Flip, Zoom and Adjust controls as available.
6. Tap Done / Export, then Save Photo.
7. Find the exported image in Downloads (browser may ask where to save).

BUILD THE ANDROID APP
1. Install Android Studio (with Android SDK Platform 34).
2. Extract this ZIP.
3. Open the rd-creations-photo-cropper-android folder in Android Studio.
4. Allow Gradle sync and install any prompted SDK components.
5. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
6. The debug APK will be at app/build/outputs/apk/debug/app-debug.apk.

NOTES
- This package contains source code, not a prebuilt APK.
- The current execution environment does not have Android SDK/Gradle installed,
  so an installable APK could not be compiled here.
- The app does not upload photos; image processing is performed locally.
